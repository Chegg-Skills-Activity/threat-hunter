# Threat Hunter Unit

A short, browser-based interactive simulation that guides learners through investigating suspicious activity as a member of a threat hunting team.

## Objective

Develop analytical thinking by guiding learners through threat identification and investigation activities.

## What learners do

- Open and investigate case files based on realistic threat scenarios
- Analyse evidence such as OSINT exposure, domain and IP reputation, and suspicious activity
- Identify indicators of compromise and assess the risk they present
- Answer guided investigation questions and progress through ranks as skills develop
- Receive feedback that explains the reasoning behind each correct answer

## Format

- Runs directly in a web browser — no installation or setup required
- Approximately 10–15 minutes to complete
- Self-paced, with progress tracked across case files

## Access note

This simulation is a complementary learning component integrated into the cybersecurity curriculum. It is intended to be completed at its designated point within the coursework, not as standalone material.
